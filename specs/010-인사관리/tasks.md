## 구현 순서

### T-010-001 프로젝트 기반 구성

- Gradle 기반 Java 21 Spring Boot 백엔드를 구성한다.
- MySQL Connector/J, Spring Data JPA, Validation, Flyway를 추가한다.
- Hibernate DDL은 validate로 설정한다.
- JavaScript 기반 React·Vite 프론트엔드를 구성한다.
- 로컬 비밀값을 저장소에 포함하지 않는 환경 설정 예제를 둔다.

관련: Q-3, Q-10.  
완료: 백엔드 테스트·빌드와 프론트엔드 린트·빌드가 빈 프로젝트에서 통과한다.

### T-010-002 초기 데이터베이스 마이그레이션

- employees, employee_number_sequences, onboarding_checklists를 만든다.
- family_members, educations, careers, certifications, foreign_worker_profiles를 만든다.

- 외국인등록번호 평문 컬럼을 만들지 않는다.

관련: FR-001~009, AC-001~009.  
완료: 빈 MySQL에 Flyway 적용과 재실행이 성공하고 JPA validate가 통과한다.

### T-010-003 사번 채번기

- `YYNNNNDD`를 생성한다.
- 연도별 회사 전체 순번을 0001부터 증가시킨다.
- 동시 요청을 원자적으로 처리한다.
- 9999 초과, 잘못된 부서 코드와 이미 사용된 부서 코드 참조를 거부한다.
- 생성된 사번을 변경하는 공개 경로를 만들지 않는다.

관련: FR-002, AC-002.  
완료: 연도 경계·동시 등록·순번 소진·부서 이동 테스트가 통과한다.
