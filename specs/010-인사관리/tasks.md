# Tasks: 010 인사관리 FR-001~009

> 근거: `specs/010-인사관리/spec.md`, `specs/010-인사관리/design.md`

## 구현 순서

### T-010-001 프로젝트 기반 구성

- Gradle 기반 Java 21 Spring Boot 백엔드를 구성한다.
- MySQL Connector/J, Spring Data JPA, Validation, Flyway를 추가한다.
- Hibernate DDL은 validate로 설정한다.
- JavaScript 기반 React·Vite 프론트엔드를 구성한다.
- 로컬 비밀값을 저장소에 포함하지 않는 환경 설정 예제를 둔다.

관련: Q-3, Q-10.  
완료: 백엔드 테스트·빌드와 프론트엔드 린트·빌드가 빈 프로젝트에서 통과한다.

### T-010-002 초기 데이터베이스 마이그레이션

- employees, employee_number_sequences, onboarding_checklists를 만든다.
- family_members, educations, careers, certifications, foreign_worker_profiles를 만든다.
- reminder_deliveries와 필요한 고유·외래키·검사 제약을 만든다.
- 외국인등록번호 평문 컬럼을 만들지 않는다.

관련: FR-001~009, AC-001~009.  
완료: 빈 MySQL에 Flyway 적용과 재실행이 성공하고 JPA validate가 통과한다.

### T-010-003 사번 채번기

- `YYNNNNDD`를 생성한다.
- 연도별 회사 전체 순번을 0001부터 증가시킨다.
- 동시 요청을 원자적으로 처리한다.
- 9999 초과, 잘못된 부서 코드와 이미 사용된 부서 코드 참조를 거부한다.
- 생성된 사번을 변경하는 공개 경로를 만들지 않는다.

관련: FR-002, AC-002.  
완료: 연도 경계·동시 등록·순번 소진·부서 이동 테스트가 통과한다.

### T-010-004 사원 등록 도메인과 유즈케이스

- Employee와 고용형태 여섯 코드를 구현한다.
- 필수 필드, 수습 기간, 외국인 조건부 필드를 검증한다.
- OrganizationReader와 권한 포트를 호출한다.
- 사원·체크리스트·등록 이벤트를 하나의 트랜잭션으로 저장한다.
- 멱등 키 재요청에 최초 결과를 반환한다.

관련: FR-001, FR-002, FR-007, FR-009; AC-001, AC-002, AC-007, AC-009; FR-038, FR-039.  
완료: 성공·검증 실패·조직 실패·롤백·중복 요청 통합 테스트가 통과한다.

### T-010-005 외국인등록번호 암호화

- 인증 암호 방식의 SensitiveValueCipher 어댑터를 구현한다.
- 키를 애플리케이션 소스 밖에서 주입한다.
- Entity, 로그, 예외와 일반 API 응답에서 원문을 제거한다.
- 마스킹된 표시값만 응답한다.
- 원문 조회 API는 만들지 않는다.

관련: FR-009, AC-009, P-6, NFR-005.  
완료: DB 직접 조회·로그 캡처·API 응답에서 평문이 발견되지 않는다.

### T-010-006 사원 등록 REST API와 React 화면

- `POST /api/hr/employees` 계약을 구현한다.
- Request/Response DTO와 오류 응답을 구현한다.
- React 등록 폼과 조건부 외국인 필드를 구현한다.
- 고용형태는 여섯 코드만 선택할 수 있게 한다.
- 접근성 이름, 오류 연결과 키보드 조작을 확인한다.

관련: FR-001, FR-007, FR-008, FR-009; AC-001, AC-007, AC-008, AC-009.  
완료: API 계약 테스트와 등록 화면 사용자 흐름 테스트가 통과한다.

### T-010-007 가족 관리

- 가족 구성원 등록·수정·조회 API를 구현한다.
- 동거·부양·장애·공제 대상 필드를 보존한다.
- 사원 소유 관계와 삭제 정책을 적용한다.

관련: FR-004, AC-004.  
완료: 부양가족 지정 결과와 권한 경계 테스트가 통과한다.

### T-010-008 학력·경력 관리

- 학력과 경력의 등록·수정·조회 API를 구현한다.
- 종료일이 시작일보다 빠른 요청을 저장 전에 거부한다.
- evidenceFileId만 저장하고 900 파일 검증 포트를 둔다.

관련: FR-005, AC-005.  
완료: 정상·역전 기간·롤백 테스트가 통과한다. 실제 파일 연결 전에는 첨부 완료로 판정하지 않는다.

### T-010-009 자격 관리

- 자격 등록·수정·조회 API를 구현한다.
- 유효기간 없는 자격을 허용한다.
- 취득일 이후의 유효기간만 허용한다.

관련: FR-006, AC-006.  
완료: 유효기간 유무와 잘못된 기간 테스트가 통과한다.

### T-010-010 인사기록카드 조회

- 사원과 가족·학력·경력·자격·발령·계약의 일곱 영역 DTO를 정의한다.
- `GET /api/hr/employees/{id}/record`를 구현한다.
- LAZY 연관을 무차별 초기화하지 않고 전용 조회를 사용한다.
- 발령·계약 미구현 영역은 안정된 빈 배열로 반환한다.

관련: FR-003, AC-003, NFR-002.  
완료: 한 응답의 일곱 영역과 쿼리 수 회귀 테스트가 통과한다.

### T-010-011 만료·수습 알림 배치

- 매일 09:00 Asia/Seoul 배치를 구현한다.
- 자격 30일, 수습 14일, 체류 60일 전 대상을 조회한다.
- NotificationSender로 내부 알림을 전달한다.
- 고유 키로 재실행과 동시 실행의 중복을 방지한다.

관련: FR-006, FR-008, FR-009; AC-006, AC-008, AC-009.  
완료: 경계일·재실행·동시 실행·실패 재시도 테스트가 통과한다.

### T-010-012 FR·AC 최종 검증

- FR-001~009와 AC-001~009를 구현·테스트에 대조한다.
- 스펙 밖 기능과 누락된 예외를 확인한다.
- 비밀키, 개인정보, 로컬 절대경로 포함 여부를 검사한다.
- 백엔드 테스트·린트·빌드와 프론트엔드 테스트·린트·빌드를 실행한다.
- 900 미연결 항목을 완료로 오판하지 않는다.

관련: FR-001~009, AC-001~009.  
완료: 검증표와 실행 결과를 PR에 기록하고 Cursor 최종 검증을 요청한다.
